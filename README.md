# Video Watermark Remover (Gemini Notebook Logo Remover) 🎬

أداة تلقائية لحذف الشعار/العلامة المائية (Watermark) لنوت بوك Gemini من مقاطع الفيديو عن طريق قص آخر 3.1 ثانية بدقة فائقة وبدون إعادة ترميز الفيديو (Stream Copy) للحفاظ على الجودة الأصلية وسرعة المعالجة الفائقة.

An automated tool to remove the Gemini Notebook watermark from videos by cleanly trimming the last 3.1 seconds using FFmpeg stream copy (no re-encoding, lossless quality, near-instant speed).

---

## 🌟 المميزات (Features)

- **📱 قابل للتثبيت على الهاتف (PWA App)**: تطبيق ويب تقدمي يمكنك تثبيته كأيقونة تطبيق كاملة على شاشة هاتفك الأندرويد.
- **🔄 استقبال الفيديوهات عبر المشاركة (Web Share Target)**: يظهر التطبيق مباشرة في قائمة مشاركة النظام (Share Sheet) في أندرويد. عند مشاركة أي فيديو من المعرض، تيك توك، واتساب، أو الملفات يتم توجيهه للتطبيق فوراً.
- **⚡ معالجة فائقة السرعة محلياً (In-Browser WebAssembly)**: معالجة الفيديوهات تتم بالكامل داخل جهازك عبر FFmpeg WASM دون الحاجة لرفعها لأي سيرفر خارجي (حفاظ تام على الخصوصية والبيانات).
- **💻 واجهة ويب عصرية (Web Dashboard)**: رفع مقاطع الفيديو، سحب وإفلات (Drag & Drop)، متابعة التقدم بنسبة مئوية، ومعاينة وتحميل الفيديو بعد التعديل.
- **🗂️ معالجة مجمعة (Batch Processing)**: دعم معالجة ملفات متعددة ومجلدات كاملة دفعة واحدة على الكمبيوتر.
- **🖱️ أداة سريعة بالسحب والإفلات (Windows Drag & Drop Batch)**: يمكنك سحب أي فيديو أو مجلد مباشرة فوق ملف `Remove_Watermark.bat`.

## 📱 التثبيت على هاتف أندرويد واستقبال المشاركات (Mobile PWA & Share Target)

### 1. خطوات التثبيت:
1. انشر المشروع على منصة **Vercel** (أو أي استضافة HTTPS تدعم الملفات الثابتة):
   - قم بربط مستودع GitHub بحسابك على [Vercel](https://vercel.com) ليتم نشره برابط آمن `https://...`.
2. افتح الرابط على هاتفك باستخدام متصفح **Google Chrome** أو **Edge**.
3. ستظهر لك لافتة بالأعلى: **"تثبيت التطبيق على هاتفك (Install App)"**، انقر على **تثبيت الآن** (أو من قائمة خيارات المتصفح ⋮ واختر *تثبيت التطبيق / Install App*).
4. سيظهر تطبيق **VideoTrimmer** الآن في قائمة تطبيقات هاتفك وعلى الشاشة الرئيسية كأي تطبيق أصلي.

### 2. طريقة مشاركة الفيديوهات من التطبيقات الأخرى:
1. افتح **الاستوديو / المعرض** أو **مدير الملفات** أو أي تطبيق فيديو بهاتفك.
2. حدد الفيديو الذي ترغب في إزالة العلامة المائية منه واضغط زر **مشاركة (Share)**.
3. اختر من قائمة التطبيقات **VideoTrimmer**.
4. سيفتح التطبيق تلقائياً، ويستقبل الفيديو ويقوم بقص آخر 3.1 ثانية في ثوانٍ معدودة، ثم يتيح لك حفظ الفيديو المعدل بضغطة زر.

## 💻 التشغيل على الكمبيوتر (Local Usage)

### 1. المتطلبات (Prerequisites)
1. **Python 3.8+**
2. **FFmpeg & FFprobe**: مضافاً إلى مسار النظام (System PATH).

### 2. تثبيت الاعتماديات
```bash
pip install -r requirements.txt
```

### 3. تشغيل واجهة الويب محلياً
انقر نقراً مزدوجاً على:
```
Start_Web_App.bat
```
أو شغّل عبر الطرفية:
```bash
python app.py
```
ثم افتح: [http://localhost:5000](http://localhost:5000)

### 4. استخدام سطر الأوامر / السحب والإفلات
- **ويندوز بالسحب والإفلات**: اسحب أي فيديو أو مجلد وأسقطه فوق ملف `Remove_Watermark.bat`.
- **سطر الأوامر**:
  ```bash
  python remove_watermark.py <مسار_الفيديو_أو_المجلد>
  ```
